# LiveBook AI 实时成交单 — 测试指南

> 目标：直播进行中，每单成交实时生成记录（书名/买家/成交价）。第一场测试目标：**跑通全流程 + 至少 3–5 条记录与实际成交对得上**。

## 1. 直播前准备（提前 30 分钟）

### 1.1 声音路由到 BlackHole（关键！）
1. 打开「系统设置 → 声音 → 输出」
2. 选择 **BlackHole 2ch**（这样直播窗口的声音会进虚拟声卡）
   - ⚠️ 选 BlackHole 后你自己就听不到了 → 用「音频 MIDI 设置」建一个**多输出设备**（BlackHole + 扬声器），把它设为输出，既进系统又听得见
3. 确认系统播放任何声音时，`run_live.py` 能看到输入

### 1.2 权限（一次性）
- 终端（运行命令的那个 App）需授予：**麦克风** + **屏幕录制**
- 设置 → 隐私与安全性 → 麦克风 / 屏幕录制 → 勾选

### 1.3 环境自检
```bash
PYTHONPATH= ~/speech2text/venv/bin/python \
  scripts/run_live.py --check
```
期望输出（全绿）：
```
=== 直播前环境自检 ===
  ✅ BlackHole 设备: OK（设备 #0）
  ✅ 麦克风权限: OK
  ✅ 屏幕录制权限: OK
  ✅ 直播窗口: 找到：[微信 微信] (...)
```
哪项 ⚠️ 就先解决哪项（见 §5）。

## 2. 启动（开播前 5 分钟）

```bash
cd ~/Documents/livebook-ai/realtime
PYTHONPATH= ~/speech2text/venv/bin/python \
  scripts/run_live.py --web 8888 --console --window-title "视频号,微信,直播"
```

**启动输出含义**（看到这些就对了）：
```
Web 面板: http://127.0.0.1:8888
定位到直播窗口: [微信 微信] (143, 26, 880, 640)   ← 找到直播窗口，只捕获它
检测到弹幕栏: x∈[0.7x, 1.0]（右侧）              ← 弹幕通道已开
（或）未检测到弹幕出价行 → 弹幕通道关闭，仅用音频+封面
实时监听中（BlackHole 音频 + 屏幕 OCR）… Ctrl-C 结束
```

然后浏览器打开 **http://127.0.0.1:8888**（实时面板：成交记录表 + 弹幕出价 + 实时转写）。

## 3. 直播中观察

| 看到什么 | 说明 |
|---|---|
| 面板「实时转写」在滚动 | 音频通道正常（主播话术被识别） |
| 面板「弹幕出价」出现 `买家甲 5 → 买家乙 10 → …` | 弹幕通道正常，出价阶梯在累积 |
| 终端/面板出现 `成交 #1 买家甲 ¥30 [SOLD] 书名…` | **一单成交了！**记录完整 |
| `[NEEDS_REVIEW]` | 有结算信号但买家/价格没凑齐 → 正常，人工补一下即可 |
| 长时间无成交记录 | 见 §5 排查 |

**注意记录**：每出现一条记录，记下大概的成交序号和时间，直播后好核对。

## 4. 直播结束

1. 终端按 **Ctrl-C**
2. 输出会打印：`本场共 N 条记录，已导出: /tmp/live_sessions/20260818_2130/…`
3. 把整个 `live_sessions/20260818_2130/` 目录里的文件发给我，包含：
   - `records.json` / `records.csv` — 成交记录
   - `transcript.txt` — 全场转写全文
   - `signals.json` — 检测到的所有成交/流拍信号
   - `danmaku.json` — 弹幕出价事件
   - `config.json` — 本次使用的区域配置

有这些我就能做一轮**校准**（补买家别名、调价格词典、调区域），下一场更准。

## 5. 常见问题排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 转写不动 | 声音没路由到 BlackHole | 设置→声音→输出选 BlackHole/多输出设备 |
| 转写在动但不出成交 | 主播话术与词典不符（如不说"恭喜/结拍"） | 直播后把 transcript.txt 给我，补信号/词典 |
| 弹幕通道关闭了 | 画面右侧没检测到"短文本+数字" | 确认直播窗口在屏幕可见位置；或加 `--no-danmaku` 不启用 |
| 记录全 NEEDS_REVIEW | 弹幕没进（通道关/识别差），音频单通道 | 优先保证弹幕通道；或人工核对后补 |
| 找不到直播窗口 | 关键词不匹配 | 用 `--window-title "窗口标题的一部分"` 指定 |
| 屏幕全黑 | 屏幕录制权限未授予/屏幕锁定 | 授权限后重启终端再跑 |
